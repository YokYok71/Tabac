Politique de confidentialité

Ma Cave à Tabac — t-cellar.app  ·  Dernière mise à jour : août 2026

Résumé

Ma Cave à Tabac est une application web progressive (PWA) personnelle, mise à disposition gratuitement, en mode « best effort ». Elle ne collecte aucune donnée utilisateur sur un serveur. Toutes vos données restent sur votre appareil.

Données stockées localement

L'application stocke les informations suivantes exclusivement sur votre appareil via localStorage :

  • Votre collection de tabacs (noms, marques, notes, lots, photos)
  • Votre collection de pipes
  • Votre liste de souhaits
  • Vos accessoires
  • Votre journal de séances
  • Vos préférences d'interface (langue, clé API)
  • Un token d'accès cloud temporaire (Google Drive ou Dropbox, si la sauvegarde automatique est activée), conservé le temps de sa validité (~1 heure pour Google Drive, ~4 heures pour Dropbox, plus un refresh token Dropbox long terme pour le renouvellement silencieux)

Ces données ne quittent jamais votre appareil sauf si vous utilisez la sauvegarde cloud (Google Drive ou Dropbox — voir ci-dessous).

Effacer toutes les données (Paramètres → Données) efface aussi les identifiants conservés : les jetons de connexion Google Drive et Dropbox (y compris le jeton de renouvellement Dropbox longue durée), les clés d'API de l'assistant IA, et l'adresse e-mail du compte Google mémorisée pour vous ré-authentifier plus vite. Après ce bouton, il ne reste rien de vous sur l'appareil — utile avant de le prêter, de le revendre ou d'en publier une capture d'écran. Vos sauvegardes déjà déposées sur le cloud ne sont pas supprimées.

Google Drive (sauvegarde optionnelle)

Si vous choisissez d'utiliser la fonctionnalité de sauvegarde, l'application demande l'accès au scope drive.appdata de votre compte Google. Ce scope permet uniquement :

  • De lire et écrire des fichiers de sauvegarde horodatés (cave-tabac-YYYYMMDD-HHMMSS-….json) dans un dossier privé réservé à l'application, invisible dans votre Google Drive. L'application conserve au maximum 3 sauvegardes manuelles et un fichier de sauvegarde automatique horodaté (cave-tabac-auto-….json, écrasé en place à chaque sauvegarde) ; les fichiers manuels les plus anciens sont supprimés automatiquement.

L'application n'accède à aucun autre fichier de votre Google Drive. L'authentification est gérée directement par Google via OAuth 2.0. Aucun token ni donnée Google n'est transmis à un tiers.

Catalogue de référence (votre fichier)

L'application n'embarque aucun catalogue. Si vous en chargez un (Paramètres → Données → Catalogue de référence), le fichier CSV que vous fournissez est conservé localement, dans une base de données du navigateur qui lui est réservée (IndexedDB « cave-catalogue »), avec une version analysée pour accélérer les recherches. Il n'est envoyé à aucun service tiers et n'est jamais transmis à un fournisseur d'IA.

Il ne quitte votre appareil que sur votre action : le bouton « Sauvegarder le catalogue dans le cloud » téléverse le CSV tel quel dans le même dossier privé que vos sauvegardes (fichier cave-tabac-catalogue-….csv), et une seule copie y est conservée. Le catalogue voyage dans son propre fichier, séparé des sauvegardes de votre cave. « Retirer le catalogue » l'efface de votre appareil ; la copie éventuellement présente dans le cloud reste, jusqu'à ce que vous la supprimiez depuis « Voir mes sauvegardes ».

Photos (locales uniquement)

Les photos s'ajoutent uniquement en important une image depuis votre appareil (bouton « Importer une photo »). Elles sont stockées localement (IndexedDB) et ne transitent par aucun service tiers. Elles ne quittent votre appareil que si vous activez la sauvegarde cloud (Google Drive ou Dropbox) : les photos sont alors incluses dans le fichier de sauvegarde, comme le reste de vos données — et chiffrées avec lui si vous avez activé le chiffrement. Elles sont également incluses dans vos exports JSON et ZIP, qui restent sur votre appareil jusqu'à ce que vous les partagiez.

Dropbox (sauvegarde optionnelle)

Si vous choisissez Dropbox comme destination de sauvegarde (Paramètres → Données → Sauvegarde cloud), l'application demande l'accès à un dossier d'application dédié (« App folder ») — Dropbox confine l'application à ce seul dossier ; elle ne voit jamais le reste de votre Dropbox. L'authentification s'effectue directement auprès de Dropbox (www.dropbox.com) via OAuth 2.0 + PKCE ; les sauvegardes transitent ensuite par api.dropboxapi.com et content.dropboxapi.com. Comme pour Google Drive, aucun jeton ni donnée Dropbox n'est transmis à un tiers, et le contenu peut être chiffré avant envoi si vous avez activé le chiffrement des sauvegardes.

Localisation des séances (optionnel)

Vous pouvez, si vous le souhaitez, attacher une position géographique à une séance du journal (bouton « Ajouter ma position » dans le formulaire de séance). La position n'est jamais capturée automatiquement — uniquement sur votre action explicite, et votre navigateur vous demande l'autorisation la première fois. Les coordonnées (latitude / longitude) sont stockées localement sur la séance, exactement comme les autres champs ; elles partent donc dans vos exports JSON / CSV et dans vos sauvegardes cloud.

Lorsque vous ouvrez le détail d'une séance qui porte une position, l'application affiche une petite carte fournie par OpenStreetMap (www.openstreetmap.org). Votre navigateur envoie alors les coordonnées de cette séance à OpenStreetMap pour récupérer l'image de la carte. OpenStreetMap est une organisation à but non lucratif ; aucune autre donnée (vos fiches, vos clés, votre identité) ne lui est transmise. Si vous ne renseignez aucune position, aucune requête n'est faite à ce service.

Lorsque vous attachez une position (à la capture), l'application peut déduire un nom de lieu à partir des coordonnées via le service de géocodage inverse d'OpenStreetMap, nominatim.openstreetmap.org. Seules les coordonnées de la séance lui sont envoyées ; le nom obtenu est enregistré localement et reste modifiable. Aucune autre donnée n'est transmise, et aucune requête n'est faite si vous n'attachez pas de position.

Assistant IA (optionnel)

Si vous configurez une clé API (Anthropic, OpenAI ou Google Gemini), l'application envoie directement depuis votre navigateur des requêtes aux API correspondantes pour l'auto-complétion des fiches tabac et pipe. Seules les informations saisies dans le champ de recherche sont transmises. Une exception : la fonction « Scanner la boîte » — si vous l'utilisez, la photo de la boîte est envoyée au fournisseur d'IA que vous avez choisi pour en lire la marque et le nom. Cette photo est réduite avant l'envoi et n'est jamais conservée par l'application. La clé API est stockée localement sur votre appareil.

Par défaut, la clé API est exclue des exports JSON et des sauvegardes cloud (Google Drive ou Dropbox). Elle n'est jamais transmise à un service tiers autre que le fournisseur d'IA que vous avez choisi. Si vous souhaitez l'inclure dans vos sauvegardes afin de faciliter la restauration sur un autre appareil, désactivez l'option Exclure les clés API des exports et sauvegardes dans ⚙️ Paramètres → section Assistant IA.

À l'inverse, une clé d'API présente dans une sauvegarde que vous importez n'est installée sur cet appareil que si vous choisissez Remplacer. Une fusion ne l'installe jamais : c'est ainsi que l'on accepte la sauvegarde de quelqu'un d'autre, et sa clé n'a pas à devenir la vôtre.

Aucun serveur propre, aucun tracking

Ma Cave à Tabac est hébergée sur GitHub Pages. L'application ne dispose d'aucun serveur propre, ne pose aucun cookie de tracking et n'intègre aucun outil d'analyse (Google Analytics, etc.).

Une exception technique : lors d'un export ZIP, la bibliothèque de compression (JSZip) est téléchargée à la demande depuis le CDN cdnjs.cloudflare.com (avec vérification d'intégrité du fichier). Ce CDN voit alors une requête de téléchargement standard (adresse IP, comme toute ressource web) — aucune de vos données n'y transite ; la compression elle-même s'effectue entièrement sur votre appareil.

Plateforme

L'application fonctionne sur navigateur web (Safari, Chrome, Firefox, etc.) et peut être installée comme PWA sur l'écran d'accueil iOS et Android. Il n'existe pas de version native iOS ou Android distribuée via l'App Store ou le Play Store.

Garanties et responsabilité

Ma Cave à Tabac est un projet personnel mis à disposition gratuitement, en mode « best effort » et « tel quel » (en l'état), sans aucune garantie. L'application est fonctionnelle et testée, mais aucune assurance n'est donnée concernant :

  • la disponibilité continue du service ;
  • l'absence de bugs, d'interruptions ou d'erreurs ;
  • la conservation des données stockées sur votre appareil — un navigateur peut effacer son cache local, un appareil peut être perdu, endommagé ou réinitialisé ;
  • l'adéquation à un usage particulier.

L'utilisation se fait sous votre seule responsabilité. Il est recommandé de :

  • Exporter régulièrement vos données via ⚙️ Paramètres → Exporter JSON ou Exporter ZIP ;
  • activer la sauvegarde automatique cloud (Google Drive ou Dropbox) si vous souhaitez une copie distante (voir section ci-dessus) ;
  • conserver au moins une copie de sauvegarde sur un emplacement distinct de votre appareil principal.

L'auteur ne saurait être tenu responsable d'une perte de données, d'une interruption de service ou de tout dommage direct ou indirect lié à l'utilisation de l'application.

Privacy Policy

My Tobacco Cellar — t-cellar.app  ·  Last updated: August 2026

Summary

My Tobacco Cellar is a personal Progressive Web App (PWA), provided free of charge on a best-effort basis. It does not collect any user data on a server. All your data stays on your device.

Locally stored data

The app stores the following data exclusively on your device via localStorage:

  • Your tobacco collection (names, brands, notes, lots, photos)
  • Your pipe collection
  • Your wishlist
  • Your accessories
  • Your session journal
  • Your UI preferences (language, API key)
  • A temporary cloud access token (Google Drive or Dropbox, when auto-backup is enabled), kept only for its validity (~1 hour for Google Drive, ~4 hours for Dropbox, plus a long-lived Dropbox refresh token for silent renewal)

This data never leaves your device unless you use the cloud backup feature (Google Drive or Dropbox — see below).

Erase all data (Settings → Data) also erases the stored credentials: the Google Drive and Dropbox access tokens (including the long-lived Dropbox refresh token), the AI assistant's API keys, and the Google account e-mail address kept to re-authenticate you faster. After that button nothing of yours is left on the device — useful before lending it, selling it, or posting a screenshot of it. Backups already stored in the cloud are not deleted.

Google Drive (optional backup)

If you choose to use the backup feature, the app requests access to the drive.appdata scope of your Google account. This scope only allows:

  • Reading and writing timestamped backup files (cave-tabac-YYYYMMDD-HHMMSS-….json) in a private folder dedicated to the app, invisible in your Google Drive. The app keeps at most 3 manual backups plus one timestamped auto-save file (cave-tabac-auto-….json, overwritten in place on each save); the oldest manual files are deleted automatically.

The app never accesses any other file in your Google Drive. Authentication is handled directly by Google via OAuth 2.0. No token or Google data is transmitted to any third party.

Reference catalogue (your file)

The app ships no catalogue. If you load one (Settings → Data → Reference catalogue), the CSV file you supply is kept locally, in a browser database reserved for it (the “cave-catalogue” IndexedDB), together with a parsed copy that makes lookups fast. It is sent to no third-party service and is never passed to an AI provider.

It leaves your device only when you ask: the “Save the catalogue to the cloud” button uploads the CSV as-is into the same private folder as your backups (a cave-tabac-catalogue-….csv file), and only one copy is kept there. The catalogue travels in its own file, separate from your cellar backups. “Remove the catalogue” erases it from your device; any copy already in the cloud stays until you delete it from “View my backups”.

Photos (local only)

Photos are added only by importing an image from your device (the "Import a photo" button). They are stored locally (IndexedDB) and go through no third-party service. They only leave your device if you enable cloud backup (Google Drive or Dropbox): photos are then included in the backup file like the rest of your data — and encrypted along with it if you enabled encryption. They are also included in your JSON and ZIP exports, which stay on your device until you share them.

Dropbox (optional backup)

If you pick Dropbox as your backup destination (Settings → Data → Cloud backup), the app requests access to a dedicated app folder — Dropbox confines the app to that single folder; it never sees the rest of your Dropbox. Authentication happens directly with Dropbox (www.dropbox.com) via OAuth 2.0 + PKCE; backups then travel through api.dropboxapi.com and content.dropboxapi.com. As with Google Drive, no token or Dropbox data is transmitted to any third party, and the content can be encrypted before upload if you enabled backup encryption.

Session location (optional)

You may optionally attach a geographic location to a journal session ("Add my location" button in the session form). The location is never captured automatically — only on your explicit tap, and your browser asks for permission the first time. The coordinates (latitude / longitude) are stored locally on the session, exactly like the other fields; they therefore travel with your JSON / CSV exports and your cloud backups.

When you open the detail of a session that carries a location, the app shows a small map provided by OpenStreetMap (www.openstreetmap.org). Your browser then sends that session's coordinates to OpenStreetMap to fetch the map image. OpenStreetMap is a non-profit organisation; no other data (your entries, your keys, your identity) is sent to it. If you never set a location, no request is made to this service.

When you attach a location (at capture time), the app may derive a place name from the coordinates using OpenStreetMap's reverse-geocoding service, nominatim.openstreetmap.org. Only the session's coordinates are sent to it; the resulting name is stored locally and stays editable. No other data is transmitted, and no request is made if you don't attach a location.

AI Assistant (optional)

If you configure an API key (Anthropic, OpenAI or Google Gemini), the app sends requests directly from your browser to the corresponding API for auto-completion of tobacco and pipe entries. Only the text you type in the search field is transmitted. One exception: the “Scan the tin” feature — if you use it, the photo of the tin is sent to the AI provider you chose so it can read the brand and name. That photo is downscaled before upload and is never stored by the app. The API key is stored locally on your device.

By default, the API key is excluded from JSON exports and cloud backups (Google Drive or Dropbox). It is never transmitted to any third party other than the AI provider you have chosen. To include it in backups for easier restoration on another device, turn off Exclude API keys from exports and backups in ⚙️ Settings → AI Assistant section.

Conversely, an API key present in a backup you import is installed on this device only if you choose Replace. A merge never installs it: merging is how you accept someone else's backup, and their key has no business becoming yours.

No own server, no tracking

My Tobacco Cellar is hosted on GitHub Pages. The app has no server of its own, sets no tracking cookies and bundles no analytics tools (Google Analytics, etc.).

One technical exception: during a ZIP export, the compression library (JSZip) is downloaded on demand from the cdnjs.cloudflare.com CDN (with file integrity verification). That CDN then sees a standard download request (IP address, like any web resource) — none of your data passes through it; the compression itself runs entirely on your device.

Platform

The app runs in any web browser (Safari, Chrome, Firefox, etc.) and can be installed as a PWA on the iOS and Android home screen. There is no native iOS or Android version distributed via the App Store or the Play Store.

Warranty and liability

My Tobacco Cellar is a personal project provided free of charge, on a "best-effort" basis and "as is", with no warranty. The app is functional and tested, but no assurance is given regarding:

  • continuous service availability;
  • the absence of bugs, interruptions or errors;
  • the preservation of data stored on your device — a browser may wipe its local cache, a device may be lost, damaged or reset;
  • fitness for any particular purpose.

Use is at your own risk. It is recommended that you:

  • Export your data regularly via ⚙️ Settings → Export JSON or Export ZIP;
  • enable the automatic cloud backup (Google Drive or Dropbox) if you want a remote copy (see section above);
  • keep at least one backup copy in a location separate from your main device.

The author may not be held liable for data loss, service interruption or any direct or indirect damage related to the use of the app.

Mi Bodega de Tabaco — t-cellar.app  ·  Última actualización: agosto de 2026

Resumen

Mi Bodega de Tabaco es una aplicación web progresiva (PWA) personal, ofrecida de forma gratuita y según el mejor esfuerzo posible. No recopila ningún dato de usuario en un servidor. Todos tus datos permanecen en tu dispositivo.

Datos almacenados localmente

La aplicación almacena los siguientes datos exclusivamente en tu dispositivo mediante localStorage:

  • Tu colección de tabacos (nombres, marcas, notas, lotes, fotos)
  • Tu colección de pipas
  • Tu lista de deseos
  • Tus accesorios
  • Tu diario de sesiones
  • Tus preferencias de interfaz (idioma, clave de API)
  • Un token temporal de acceso a la nube (Google Drive o Dropbox, cuando la copia de seguridad automática está activada), conservado únicamente durante su validez (~1 hora para Google Drive, ~4 horas para Dropbox, más un token de actualización de larga duración de Dropbox para la renovación silenciosa)

Estos datos nunca salen de tu dispositivo, a menos que utilices la función de copia de seguridad en la nube (Google Drive o Dropbox, véase más abajo).

Eliminar todos los datos (Ajustes → Datos) borra también las credenciales guardadas: los tokens de conexión de Google Drive y Dropbox (incluido el token de actualización de larga duración de Dropbox), las claves de API del asistente de IA y la dirección de correo de la cuenta de Google memorizada para volver a autenticarte más rápido. Después de ese botón no queda nada tuyo en el dispositivo — útil antes de prestarlo, venderlo o publicar una captura de pantalla. Tus copias de seguridad ya guardadas en la nube no se eliminan.

Google Drive (copia de seguridad opcional)

Si decides usar la función de copia de seguridad, la aplicación solicita acceso al ámbito drive.appdata de tu cuenta de Google. Este ámbito solo permite:

  • Leer y escribir archivos de copia de seguridad con marca de tiempo (cave-tabac-YYYYMMDD-HHMMSS-….json) en una carpeta privada dedicada a la aplicación, invisible en tu Google Drive. La aplicación conserva como máximo 3 copias de seguridad manuales más un archivo de guardado automático con marca de tiempo (cave-tabac-auto-….json, sobrescrito en el mismo lugar en cada guardado); los archivos manuales más antiguos se eliminan automáticamente.

La aplicación nunca accede a ningún otro archivo de tu Google Drive. La autenticación la gestiona directamente Google mediante OAuth 2.0. Ningún token ni dato de Google se transmite a terceros.

Catálogo de referencia (tu archivo)

La app no incluye ningún catálogo. Si cargas uno (Ajustes → Datos → Catálogo de referencia), el archivo CSV que aportas se guarda localmente, en una base de datos del navegador reservada para él (IndexedDB «cave-catalogue»), junto con una versión analizada que acelera las búsquedas. No se envía a ningún servicio de terceros y nunca se transmite a un proveedor de IA.

Solo sale de tu dispositivo si tú lo pides: el botón «Guardar el catálogo en la nube» sube el CSV tal cual a la misma carpeta privada que tus copias de seguridad (un archivo cave-tabac-catalogue-….csv), y allí se conserva una sola copia. El catálogo viaja en su propio archivo, separado de las copias de tu bodega. «Quitar el catálogo» lo borra de tu dispositivo; la copia que hubiera en la nube permanece hasta que la elimines desde «Ver mis copias».

Fotos (solo locales)

Las fotos se añaden únicamente importando una imagen desde tu dispositivo (el botón «Importar una foto»). Se almacenan localmente (IndexedDB) y no pasan por ningún servicio de terceros. Solo salen de tu dispositivo si activas la copia de seguridad en la nube (Google Drive o Dropbox): las fotos se incluyen entonces en el archivo de copia como el resto de tus datos, y se cifran con él si has activado el cifrado. También se incluyen en tus exportaciones JSON y ZIP, que permanecen en tu dispositivo hasta que las compartas.

Dropbox (copia de seguridad opcional)

Si eliges Dropbox como destino de tu copia de seguridad (Ajustes → Datos → Copia de seguridad en la nube), la aplicación solicita acceso a una carpeta de aplicación dedicada: Dropbox limita la aplicación a esa única carpeta; nunca ve el resto de tu Dropbox. La autenticación se realiza directamente con Dropbox (www.dropbox.com) mediante OAuth 2.0 + PKCE; las copias de seguridad viajan luego a través de api.dropboxapi.com y content.dropboxapi.com. Al igual que con Google Drive, ningún token ni dato de Dropbox se transmite a terceros, y el contenido puede cifrarse antes de subirse si has activado el cifrado de las copias de seguridad.

Ubicación de la sesión (opcional)

Puedes adjuntar opcionalmente una ubicación geográfica a una sesión del diario (botón «Añadir mi ubicación» en el formulario de sesión). La ubicación nunca se captura automáticamente: solo con tu toque explícito, y tu navegador te pide permiso la primera vez. Las coordenadas (latitud / longitud) se almacenan localmente en la sesión, exactamente igual que los demás campos; por lo tanto, se incluyen en tus exportaciones JSON / CSV y en tus copias de seguridad en la nube.

Cuando abres el detalle de una sesión que lleva una ubicación, la aplicación muestra un pequeño mapa proporcionado por OpenStreetMap (www.openstreetmap.org). Tu navegador envía entonces las coordenadas de esa sesión a OpenStreetMap para obtener la imagen del mapa. OpenStreetMap es una organización sin ánimo de lucro; no se le envía ningún otro dato (tus entradas, tus claves, tu identidad). Si nunca defines una ubicación, no se realiza ninguna solicitud a este servicio.

Cuando adjuntas una ubicación (en el momento de la captura), la aplicación puede derivar un nombre de lugar a partir de las coordenadas usando el servicio de geocodificación inversa de OpenStreetMap, nominatim.openstreetmap.org. Solo se le envían las coordenadas de la sesión; el nombre resultante se almacena localmente y sigue siendo editable. No se transmite ningún otro dato, y no se realiza ninguna solicitud si no adjuntas una ubicación.

Asistente de IA (opcional)

Si configuras una clave de API (Anthropic, OpenAI o Google Gemini), la aplicación envía solicitudes directamente desde tu navegador a la API correspondiente para autocompletar entradas de tabacos y pipas. Solo se transmite el texto que escribes en el campo de búsqueda. Una excepción: la función «Escanear la lata»: si la usas, la foto de la lata se envía al proveedor de IA que hayas elegido para leer la marca y el nombre. Esa foto se reduce antes del envío y la aplicación nunca la conserva. La clave de API se almacena localmente en tu dispositivo.

De forma predeterminada, la clave de API está excluida de las exportaciones JSON y de las copias de seguridad en la nube (Google Drive o Dropbox). Nunca se transmite a ningún tercero que no sea el proveedor de IA que hayas elegido. Para incluirla en las copias de seguridad y facilitar la restauración en otro dispositivo, desactiva Excluir claves API de exportaciones y copias de seguridad en ⚙️ Ajustes → sección Asistente IA.

A la inversa, una clave de API presente en una copia de seguridad que importas solo se instala en este dispositivo si eliges Reemplazar. Una fusión nunca la instala: fusionar es la forma de aceptar la copia de otra persona, y su clave no tiene por qué convertirse en la tuya.

Sin servidor propio, sin seguimiento

Mi Bodega de Tabaco está alojada en GitHub Pages. La aplicación no tiene servidor propio, no instala ninguna cookie de seguimiento y no incluye ninguna herramienta de análisis (Google Analytics, etc.).

Una excepción técnica: durante una exportación ZIP, la biblioteca de compresión (JSZip) se descarga bajo demanda desde el CDN cdnjs.cloudflare.com (con verificación de integridad del archivo). Ese CDN ve entonces una solicitud de descarga estándar (dirección IP, como cualquier recurso web): ninguno de tus datos pasa por él; la compresión en sí se ejecuta por completo en tu dispositivo.

Plataforma

La aplicación funciona en cualquier navegador web (Safari, Chrome, Firefox, etc.) y puede instalarse como PWA en la pantalla de inicio de iOS y Android. No existe una versión nativa de iOS o Android distribuida a través de la App Store o de Play Store.

Garantía y responsabilidad

Mi Bodega de Tabaco es un proyecto personal ofrecido de forma gratuita, según el «mejor esfuerzo» y «tal cual», sin ninguna garantía. La aplicación es funcional y está probada, pero no se ofrece ninguna garantía respecto a:

  • la disponibilidad continua del servicio;
  • la ausencia de errores, interrupciones o fallos;
  • la conservación de los datos almacenados en tu dispositivo: un navegador puede borrar su caché local, un dispositivo puede perderse, dañarse o restablecerse;
  • la idoneidad para un propósito determinado.

El uso es bajo tu propia responsabilidad. Se recomienda que:

  • Exportes tus datos con regularidad mediante ⚙️ Ajustes → Exportar JSON o Exportar ZIP;
  • actives la copia de seguridad automática en la nube (Google Drive o Dropbox) si quieres una copia remota (véase la sección anterior);

Zusammenfassung

Mein Tabakkeller ist eine persönliche Progressive Web App (PWA), die kostenlos und nach bestem Bemühen bereitgestellt wird. Sie erfasst keine Nutzerdaten auf einem Server. Alle deine Daten bleiben auf deinem Gerät.

Lokal gespeicherte Daten

Die App speichert die folgenden Daten ausschließlich auf deinem Gerät über localStorage:

  • Deine Tabaksammlung (Namen, Marken, Notizen, Chargen, Fotos)
  • Deine Pfeifensammlung
  • Deine Wunschliste
  • Dein Zubehör
  • Dein Sitzungstagebuch
  • Deine Oberflächeneinstellungen (Sprache, API-Schlüssel)
  • Ein temporäres Cloud-Zugriffstoken (Google Drive oder Dropbox, wenn die automatische Sicherung aktiviert ist), das nur für die Dauer seiner Gültigkeit aufbewahrt wird (~1 Stunde bei Google Drive, ~4 Stunden bei Dropbox, zuzüglich eines langlebigen Dropbox-Refresh-Tokens für die stille Erneuerung)

Diese Daten verlassen dein Gerät nie, es sei denn, du nutzt die Cloud-Sicherungsfunktion (Google Drive oder Dropbox – siehe unten).

Alle Daten löschen (Einstellungen → Daten) löscht auch die gespeicherten Zugangsdaten: die Zugriffstoken von Google Drive und Dropbox (einschließlich des langlebigen Dropbox-Refresh-Tokens), die API-Schlüssel des KI-Assistenten und die E-Mail-Adresse des Google-Kontos, die für eine schnellere erneute Anmeldung gemerkt wird. Nach dieser Schaltfläche bleibt nichts von dir auf dem Gerät zurück – nützlich, bevor du es verleihst, verkaufst oder einen Screenshot davon veröffentlichst. Bereits in der Cloud abgelegte Sicherungen werden nicht gelöscht.

Google Drive (optionale Sicherung)

Wenn du die Sicherungsfunktion nutzen möchtest, fordert die App Zugriff auf den Bereich drive.appdata deines Google-Kontos an. Dieser Bereich erlaubt nur:

  • Das Lesen und Schreiben von Sicherungsdateien mit Zeitstempel (cave-tabac-YYYYMMDD-HHMMSS-….json) in einem privaten, der App vorbehaltenen Ordner, der in deinem Google Drive unsichtbar ist. Die App bewahrt höchstens 3 manuelle Sicherungen sowie eine automatische Sicherungsdatei mit Zeitstempel auf (cave-tabac-auto-….json, die bei jeder Sicherung an Ort und Stelle überschrieben wird); die ältesten manuellen Dateien werden automatisch gelöscht.

Die App greift nie auf eine andere Datei in deinem Google Drive zu. Die Authentifizierung wird direkt von Google über OAuth 2.0 abgewickelt. Es werden keine Tokens oder Google-Daten an Dritte übermittelt.

Referenzkatalog (deine Datei)

Die App enthält keinen Katalog. Wenn du einen lädst (Einstellungen → Daten → Referenzkatalog), wird die von dir bereitgestellte CSV-Datei lokal gespeichert, in einer eigens dafür reservierten Browser-Datenbank (IndexedDB „cave-catalogue“), zusammen mit einer ausgewerteten Fassung für schnelle Suchen. Sie geht an keinen Drittanbieterdienst und wird nie an einen KI-Anbieter übermittelt.

Sie verlässt dein Gerät nur auf deine Aktion hin: Die Schaltfläche „Katalog in die Cloud sichern“ lädt die CSV-Datei unverändert in denselben privaten Ordner wie deine Sicherungen (eine Datei cave-tabac-catalogue-….csv), und dort wird nur eine Kopie aufbewahrt. Der Katalog reist in seiner eigenen Datei, getrennt von den Sicherungen deines Bestands. „Katalog entfernen“ löscht ihn von deinem Gerät; eine bereits in der Cloud liegende Kopie bleibt, bis du sie unter „Meine Sicherungen ansehen“ löschst.

Fotos (nur lokal)

Fotos werden nur durch das Importieren eines Bildes von deinem Gerät hinzugefügt (Schaltfläche „Foto importieren“). Sie werden lokal gespeichert (IndexedDB) und durchlaufen keinen Drittanbieterdienst. Sie verlassen dein Gerät nur, wenn du die Cloud-Sicherung aktivierst (Google Drive oder Dropbox): Die Fotos sind dann wie deine übrigen Daten in der Sicherungsdatei enthalten – und mit ihr verschlüsselt, falls du die Verschlüsselung aktiviert hast. Sie sind ebenfalls in deinen JSON- und ZIP-Exporten enthalten, die auf deinem Gerät bleiben, bis du sie weitergibst.

Dropbox (optionale Sicherung)

Wenn du Dropbox als Ziel deiner Sicherung wählst (Einstellungen → Daten → Cloud-Sicherung), fordert die App Zugriff auf einen dedizierten App-Ordner an – Dropbox beschränkt die App auf diesen einen Ordner; sie sieht den Rest deiner Dropbox nie. Die Authentifizierung erfolgt direkt bei Dropbox (www.dropbox.com) über OAuth 2.0 + PKCE; die Sicherungen wandern dann über api.dropboxapi.com und content.dropboxapi.com. Wie bei Google Drive werden keine Tokens oder Dropbox-Daten an Dritte übermittelt, und der Inhalt kann vor dem Hochladen verschlüsselt werden, wenn du die Verschlüsselung der Sicherungen aktiviert hast.

Sitzungsstandort (optional)

Du kannst einer Tagebuchsitzung optional einen geografischen Standort hinzufügen (Schaltfläche „Meinen Ort hinzufügen“ im Sitzungsformular). Der Standort wird nie automatisch erfasst – nur auf deine ausdrückliche Berührung hin, und dein Browser fragt beim ersten Mal um Erlaubnis. Die Koordinaten (Breitengrad / Längengrad) werden lokal in der Sitzung gespeichert, genau wie die anderen Felder; sie wandern daher mit deinen JSON-/CSV-Exporten und deinen Cloud-Sicherungen mit.

Wenn du die Detailansicht einer Sitzung öffnest, die einen Standort enthält, zeigt die App eine kleine Karte an, die von OpenStreetMap (www.openstreetmap.org) bereitgestellt wird. Dein Browser sendet dann die Koordinaten dieser Sitzung an OpenStreetMap, um das Kartenbild abzurufen. OpenStreetMap ist eine gemeinnützige Organisation; es werden keine weiteren Daten (deine Einträge, deine Schlüssel, deine Identität) an sie gesendet. Wenn du nie einen Standort festlegst, wird an diesen Dienst keine Anfrage gestellt.

Wenn du einen Standort hinzufügst (zum Zeitpunkt der Erfassung), kann die App aus den Koordinaten einen Ortsnamen ableiten, indem sie den Reverse-Geocoding-Dienst von OpenStreetMap, nominatim.openstreetmap.org, verwendet. Es werden nur die Koordinaten der Sitzung an ihn gesendet; der resultierende Name wird lokal gespeichert und bleibt bearbeitbar. Es werden keine weiteren Daten übermittelt, und es wird keine Anfrage gestellt, wenn du keinen Standort hinzufügst.

KI-Assistent (optional)

Wenn du einen API-Schlüssel konfigurierst (Anthropic, OpenAI oder Google Gemini), sendet die App Anfragen direkt aus deinem Browser an die entsprechende API, um Tabak- und Pfeifeneinträge automatisch zu vervollständigen. Es wird nur der Text übermittelt, den du in das Suchfeld eingibst. Eine Ausnahme: die Funktion „Dose scannen“ – wenn du sie nutzt, wird das Foto der Dose an den von dir gewählten KI-Anbieter gesendet, damit Marke und Name gelesen werden können. Dieses Foto wird vor dem Senden verkleinert und von der App niemals gespeichert. Der API-Schlüssel wird lokal auf deinem Gerät gespeichert.

Standardmäßig ist der API-Schlüssel von JSON-Exporten und Cloud-Sicherungen (Google Drive oder Dropbox) ausgeschlossen. Er wird nie an einen anderen Dritten als den von dir gewählten KI-Anbieter übermittelt. Um ihn zur einfacheren Wiederherstellung auf einem anderen Gerät in die Sicherungen aufzunehmen, deaktiviere API-Schlüssel von Exporten und Sicherungen ausschließen in ⚙️ Einstellungen → Abschnitt KI-Assistent.

Umgekehrt wird ein API-Schlüssel, der in einer von dir importierten Sicherung enthalten ist, nur dann auf diesem Gerät eingerichtet, wenn du Ersetzen wählst. Ein Zusammenführen richtet ihn nie ein: So nimmt man die Sicherung einer anderen Person an, und deren Schlüssel soll nicht zu deinem werden.

Kein eigener Server, kein Tracking

Mein Tabakkeller wird auf GitHub Pages gehostet. Die App hat keinen eigenen Server, setzt keine Tracking-Cookies und bindet keine Analysewerkzeuge (Google Analytics usw.) ein.

Eine technische Ausnahme: Während eines ZIP-Exports wird die Komprimierungsbibliothek (JSZip) bei Bedarf vom CDN cdnjs.cloudflare.com heruntergeladen (mit Integritätsprüfung der Datei). Dieses CDN sieht dann eine standardmäßige Download-Anfrage (IP-Adresse, wie bei jeder Web-Ressource) – keine deiner Daten durchläuft es; die Komprimierung selbst läuft vollständig auf deinem Gerät ab.

Plattform

Die App läuft in jedem Webbrowser (Safari, Chrome, Firefox usw.) und kann als PWA auf dem Startbildschirm von iOS und Android installiert werden. Es gibt keine native iOS- oder Android-Version, die über den App Store oder den Play Store vertrieben wird.

Gewährleistung und Haftung

Mein Tabakkeller ist ein persönliches Projekt, das kostenlos, nach „bestem Bemühen“ und „wie besehen“ ohne jegliche Gewährleistung bereitgestellt wird. Die App ist funktionsfähig und getestet, es wird jedoch keine Zusicherung gegeben hinsichtlich:

  • der kontinuierlichen Verfügbarkeit des Dienstes;
  • der Abwesenheit von Fehlern, Unterbrechungen oder Störungen;
  • der Erhaltung der auf deinem Gerät gespeicherten Daten – ein Browser kann seinen lokalen Cache löschen, ein Gerät kann verloren gehen, beschädigt oder zurückgesetzt werden;
  • der Eignung für einen bestimmten Zweck.

Die Nutzung erfolgt auf eigenes Risiko. Es wird empfohlen, dass du:

  • Deine Daten regelmäßig exportierst über ⚙️ Einstellungen → JSON exportieren oder ZIP exportieren;
  • die automatische Cloud-Sicherung (Google Drive oder Dropbox) aktivierst, wenn du eine entfernte Kopie möchtest (siehe Abschnitt oben);
  • mindestens eine Sicherungskopie an einem von deinem Hauptgerät getrennten Ort aufbewahrst.

Der Autor kann nicht für Datenverlust, Dienstunterbrechungen oder direkte oder indirekte Schäden haftbar gemacht werden, die mit der Nutzung der App zusammenhängen.

La Mia Cantina del Tabacco — t-cellar.app  ·  Ultimo aggiornamento: agosto 2026

In breve

La Mia Cantina del Tabacco è un'applicazione web progressiva (PWA) personale, offerta gratuitamente e secondo il miglior impegno possibile. Non raccoglie alcun dato dell'utente su un server. Tutti i tuoi dati restano sul tuo dispositivo.

Dati memorizzati localmente

L'applicazione memorizza i seguenti dati esclusivamente sul tuo dispositivo tramite localStorage:

  • La tua collezione di tabacchi (nomi, marche, note, lotti, foto)
  • La tua collezione di pipe
  • La tua lista dei desideri
  • I tuoi accessori
  • Il tuo diario delle sessioni
  • Le tue preferenze dell'interfaccia (lingua, chiave API)
  • Un token temporaneo di accesso al cloud (Google Drive o Dropbox, quando il backup automatico è attivo), conservato solo per la durata della sua validità (~1 ora per Google Drive, ~4 ore per Dropbox, più un token di aggiornamento Dropbox a lunga durata per il rinnovo silenzioso)

Questi dati non lasciano mai il tuo dispositivo, a meno che tu non utilizzi la funzione di backup nel cloud (Google Drive o Dropbox, vedi sotto).

Elimina tutti i dati (Impostazioni → Dati) cancella anche le credenziali conservate: i token di accesso di Google Drive e Dropbox (compreso il token di rinnovo Dropbox a lunga durata), le chiavi API dell'assistente IA e l'indirizzo e-mail dell'account Google memorizzato per riautenticarti più rapidamente. Dopo quel pulsante non resta nulla di tuo sul dispositivo — utile prima di prestarlo, rivenderlo o pubblicarne uno screenshot. I backup già depositati nel cloud non vengono eliminati.

Google Drive (backup opzionale)

Se scegli di usare la funzione di backup, l'applicazione richiede l'accesso all'ambito drive.appdata del tuo account Google. Questo ambito consente solo di:

  • Leggere e scrivere file di backup con marca temporale (cave-tabac-YYYYMMDD-HHMMSS-….json) in una cartella privata dedicata all'applicazione, invisibile nel tuo Google Drive. L'applicazione conserva al massimo 3 backup manuali più un file di salvataggio automatico con marca temporale (cave-tabac-auto-….json, sovrascritto sul posto a ogni salvataggio); i file manuali più vecchi vengono eliminati automaticamente.

L'applicazione non accede mai ad alcun altro file del tuo Google Drive. L'autenticazione è gestita direttamente da Google tramite OAuth 2.0. Nessun token o dato Google viene trasmesso a terzi.

Catalogo di riferimento (il tuo file)

L'app non include alcun catalogo. Se ne carichi uno (Impostazioni → Dati → Catalogo di riferimento), il file CSV che fornisci resta in locale, in un database del browser riservato a esso (IndexedDB «cave-catalogue»), insieme a una versione già analizzata che rende rapide le ricerche. Non viene inviato ad alcun servizio di terzi e non è mai trasmesso a un fornitore di IA.

Lascia il tuo dispositivo solo su tua richiesta: il pulsante «Salva il catalogo nel cloud» carica il CSV così com'è nella stessa cartella privata delle tue copie (un file cave-tabac-catalogue-….csv), e lì ne viene conservata una sola. Il catalogo viaggia nel suo file, separato dalle copie della tua cantina. «Rimuovi il catalogo» lo cancella dal tuo dispositivo; l'eventuale copia nel cloud rimane finché non la elimini da «Vedi le mie copie».

Foto (solo locali)

Le foto si aggiungono solo importando un'immagine dal dispositivo (il pulsante «Importa una foto»). Vengono archiviate localmente (IndexedDB) e non passano attraverso alcun servizio di terzi. Lasciano il dispositivo solo se attivi il backup nel cloud (Google Drive o Dropbox): le foto vengono allora incluse nel file di backup come il resto dei tuoi dati, e cifrate con esso se hai attivato la cifratura. Sono incluse anche nelle esportazioni JSON e ZIP, che restano sul tuo dispositivo fino a quando non le condividi.

Dropbox (backup opzionale)

Se scegli Dropbox come destinazione del tuo backup (Impostazioni → Dati → Backup nel cloud), l'applicazione richiede l'accesso a una cartella dedicata all'app – Dropbox limita l'applicazione a quella singola cartella; non vede mai il resto del tuo Dropbox. L'autenticazione avviene direttamente con Dropbox (www.dropbox.com) tramite OAuth 2.0 + PKCE; i backup viaggiano poi attraverso api.dropboxapi.com e content.dropboxapi.com. Come con Google Drive, nessun token o dato Dropbox viene trasmesso a terzi, e il contenuto può essere cifrato prima del caricamento se hai attivato la cifratura dei backup.

Posizione della sessione (opzionale)

Puoi facoltativamente allegare una posizione geografica a una sessione del diario (pulsante «Aggiungi la mia posizione» nel modulo della sessione). La posizione non viene mai acquisita automaticamente: solo con il tuo tocco esplicito, e il tuo browser chiede il permesso la prima volta. Le coordinate (latitudine / longitudine) vengono memorizzate localmente nella sessione, esattamente come gli altri campi; viaggiano quindi con le tue esportazioni JSON / CSV e con i tuoi backup nel cloud.

Quando apri il dettaglio di una sessione che contiene una posizione, l'applicazione mostra una piccola mappa fornita da OpenStreetMap (www.openstreetmap.org). Il tuo browser invia quindi le coordinate di quella sessione a OpenStreetMap per recuperare l'immagine della mappa. OpenStreetMap è un'organizzazione senza scopo di lucro; nessun altro dato (le tue voci, le tue chiavi, la tua identità) le viene inviato. Se non imposti mai una posizione, non viene effettuata alcuna richiesta a questo servizio.

Quando alleghi una posizione (al momento dell'acquisizione), l'applicazione può ricavare un nome di luogo dalle coordinate usando il servizio di geocodifica inversa di OpenStreetMap, nominatim.openstreetmap.org. Gli vengono inviate solo le coordinate della sessione; il nome risultante viene memorizzato localmente e resta modificabile. Nessun altro dato viene trasmesso, e non viene effettuata alcuna richiesta se non alleghi una posizione.

Assistente IA (opzionale)

Se configuri una chiave API (Anthropic, OpenAI o Google Gemini), l'applicazione invia richieste direttamente dal tuo browser all'API corrispondente per il completamento automatico delle voci di tabacchi e pipe. Viene trasmesso solo il testo che digiti nel campo di ricerca. Un'eccezione: la funzione «Scansiona la latta»: se la usi, la foto della scatola viene inviata al fornitore di IA che hai scelto per leggerne marca e nome. Questa foto viene ridotta prima dell'invio e non viene mai conservata dall'applicazione. La chiave API viene memorizzata localmente sul tuo dispositivo.

Per impostazione predefinita, la chiave API è esclusa dalle esportazioni JSON e dai backup nel cloud (Google Drive o Dropbox). Non viene mai trasmessa ad alcun terzo diverso dal fornitore di IA che hai scelto. Per includerla nei backup e facilitare il ripristino su un altro dispositivo, disattiva Escludi le chiavi API da esportazioni e backup in ⚙️ Impostazioni → sezione Assistente IA.

Viceversa, una chiave API presente in un backup che importi viene installata su questo dispositivo solo se scegli Sostituisci. Una fusione non la installa mai: è così che si accetta il backup di qualcun altro, e la sua chiave non deve diventare la tua.

Nessun server proprio, nessun tracciamento

La Mia Cantina del Tabacco è ospitata su GitHub Pages. L'applicazione non ha un server proprio, non imposta alcun cookie di tracciamento e non include alcuno strumento di analisi (Google Analytics, ecc.).

Un'eccezione tecnica: durante un'esportazione ZIP, la libreria di compressione (JSZip) viene scaricata su richiesta dal CDN cdnjs.cloudflare.com (con verifica dell'integrità del file). Quel CDN vede quindi una normale richiesta di download (indirizzo IP, come qualsiasi risorsa web): nessuno dei tuoi dati vi transita; la compressione stessa avviene interamente sul tuo dispositivo.

Piattaforma

L'applicazione funziona in qualsiasi browser web (Safari, Chrome, Firefox, ecc.) e può essere installata come PWA sulla schermata iniziale di iOS e Android. Non esiste una versione nativa iOS o Android distribuita tramite l'App Store o il Play Store.

Garanzia e responsabilità

La Mia Cantina del Tabacco è un progetto personale offerto gratuitamente, secondo il «miglior impegno» e «così com'è», senza alcuna garanzia. L'applicazione è funzionante e testata, ma non viene fornita alcuna assicurazione riguardo a:

  • la disponibilità continua del servizio;
  • l'assenza di bug, interruzioni o errori;
  • la conservazione dei dati memorizzati sul tuo dispositivo: un browser può cancellare la sua cache locale, un dispositivo può essere perso, danneggiato o ripristinato;
  • l'idoneità a uno scopo particolare.

L'uso è a tuo rischio. Si raccomanda di:

  • Esportare i tuoi dati regolarmente tramite ⚙️ Impostazioni → Esporta JSON o Esporta ZIP;
  • attivare il backup automatico nel cloud (Google Drive o Dropbox) se desideri una copia remota (vedi la sezione sopra);
  • conservare almeno una copia di backup in un luogo separato dal tuo dispositivo principale.

L'autore non può essere ritenuto responsabile per la perdita di dati, l'interruzione del servizio o qualsiasi danno diretto o indiretto legato all'uso dell'applicazione.

Resumo

A Minha Adega de Tabaco é uma aplicação web progressiva (PWA) pessoal, disponibilizada gratuitamente e na medida do possível. Não recolhe quaisquer dados do utilizador num servidor. Todos os seus dados permanecem no seu dispositivo.

Dados guardados localmente

A aplicação guarda os seguintes dados exclusivamente no seu dispositivo através de localStorage:

  • A sua coleção de tabacos (nomes, marcas, notas, lotes, fotografias)
  • A sua coleção de cachimbos
  • A sua lista de desejos
  • Os seus acessórios
  • O seu diário de sessões
  • As suas preferências de interface (idioma, chave de API)
  • Um token temporário de acesso à nuvem (Google Drive ou Dropbox, quando a cópia de segurança automática está ativa), conservado apenas durante a sua validade (~1 hora no Google Drive, ~4 horas no Dropbox, mais um token de renovação de longa duração do Dropbox para renovação silenciosa)

Estes dados nunca saem do seu dispositivo, exceto se utilizar a funcionalidade de cópia de segurança na nuvem (Google Drive ou Dropbox — ver abaixo).

Eliminar todos os dados (Definições → Dados) apaga também as credenciais guardadas: os tokens de ligação ao Google Drive e ao Dropbox (incluindo o token de renovação de longa duração do Dropbox), as chaves de API do assistente de IA e o endereço de e-mail da conta Google memorizado para o voltar a autenticar mais depressa. Depois deste botão não fica nada de si no dispositivo — útil antes de o emprestar, de o vender ou de publicar uma captura de ecrã. As cópias de segurança já guardadas na nuvem não são eliminadas.

Google Drive (cópia de segurança opcional)

Se optar por utilizar a funcionalidade de cópia de segurança, a aplicação solicita acesso ao âmbito drive.appdata da sua conta Google. Este âmbito permite apenas:

  • Ler e escrever ficheiros de cópia de segurança com data e hora (cave-tabac-AAAAMMDD-HHMMSS-….json) numa pasta privada dedicada à aplicação, invisível no seu Google Drive. A aplicação conserva no máximo 3 cópias manuais mais um ficheiro de gravação automática com data e hora (cave-tabac-auto-….json, substituído no mesmo lugar em cada gravação); os ficheiros manuais mais antigos são eliminados automaticamente.

A aplicação nunca acede a qualquer outro ficheiro do seu Google Drive. A autenticação é feita diretamente pela Google através de OAuth 2.0. Nenhum token nem dados da Google são transmitidos a terceiros.

Catálogo de referência (o seu ficheiro)

A aplicação não inclui qualquer catálogo. Se carregar um (Definições → Dados → Catálogo de referência), o ficheiro CSV que fornece fica guardado localmente, numa base de dados do navegador reservada para ele (IndexedDB «cave-catalogue»), juntamente com uma versão já analisada que torna as pesquisas rápidas. Não é enviado a qualquer serviço de terceiros e nunca é transmitido a um fornecedor de IA.

Só sai do seu aparelho por ação sua: o botão «Guardar o catálogo na nuvem» envia o CSV tal como está para a mesma pasta privada das suas cópias (um ficheiro cave-tabac-catalogue-….csv), e aí é conservada uma única cópia. O catálogo viaja no seu próprio ficheiro, separado das cópias da sua cave. «Remover o catálogo» apaga-o do seu aparelho; a cópia que exista na nuvem permanece até a eliminar em «Ver as minhas cópias».

Fotografias (apenas locais)

As fotografias são adicionadas apenas através da importação de uma imagem do seu dispositivo (botão «Importar uma foto»). São guardadas localmente (IndexedDB) e não passam por qualquer serviço de terceiros. Só saem do seu dispositivo se ativar a cópia de segurança na nuvem (Google Drive ou Dropbox): as fotografias são então incluídas no ficheiro de cópia de segurança, tal como os restantes dados — e cifradas com ele se tiver ativado a cifragem. São também incluídas nas suas exportações JSON e ZIP, que permanecem no seu dispositivo até as partilhar.

Dropbox (cópia de segurança opcional)

Se escolher o Dropbox como destino da cópia de segurança (Configurações → Dados → Cópia de segurança na nuvem), a aplicação solicita acesso a uma pasta dedicada à aplicação — o Dropbox confina a aplicação a essa única pasta; nunca vê o resto do seu Dropbox. A autenticação é feita diretamente com o Dropbox (www.dropbox.com) através de OAuth 2.0 + PKCE; as cópias de segurança circulam depois por api.dropboxapi.com e content.dropboxapi.com. Tal como no Google Drive, nenhum token nem dados do Dropbox são transmitidos a terceiros, e o conteúdo pode ser cifrado antes do envio se tiver ativado a cifragem das cópias de segurança.

Localização das sessões (opcional)

Pode, opcionalmente, associar uma localização geográfica a uma sessão do diário (botão «Adicionar a minha posição» no formulário da sessão). A localização nunca é captada automaticamente — apenas quando premir explicitamente, e o seu navegador pede autorização na primeira vez. As coordenadas (latitude / longitude) são guardadas localmente na sessão, exatamente como os outros campos; acompanham por isso as suas exportações JSON / CSV e as suas cópias de segurança na nuvem.

Quando abre o detalhe de uma sessão que tem uma localização, a aplicação mostra um pequeno mapa fornecido pelo OpenStreetMap (www.openstreetmap.org). O seu navegador envia então as coordenadas dessa sessão ao OpenStreetMap para obter a imagem do mapa. O OpenStreetMap é uma organização sem fins lucrativos; nenhum outro dado (os seus registos, as suas chaves, a sua identidade) lhe é enviado. Se nunca definir uma localização, não é feito qualquer pedido a este serviço.

Quando associa uma localização (no momento da captação), a aplicação pode obter um nome de local a partir das coordenadas, utilizando o serviço de geocodificação inversa do OpenStreetMap, nominatim.openstreetmap.org. Só as coordenadas da sessão lhe são enviadas; o nome obtido é guardado localmente e permanece editável. Nenhum outro dado é transmitido e não é feito qualquer pedido se não associar uma localização.

Assistente de IA (opcional)

Se configurar uma chave de API (Anthropic, OpenAI ou Google Gemini), a aplicação envia pedidos diretamente do seu navegador para a API correspondente, para preenchimento automático dos registos de tabacos e cachimbos. Apenas o texto que escreve no campo de pesquisa é transmitido. Uma exceção: a funcionalidade «Digitalizar a lata» — se a utilizar, a fotografia da lata é enviada ao fornecedor de IA que escolheu para que possa ler a marca e o nome. Essa fotografia é reduzida antes do envio e nunca é guardada pela aplicação. A chave de API é guardada localmente no seu dispositivo.

Por predefinição, a chave de API é excluída das exportações JSON e das cópias de segurança na nuvem (Google Drive ou Dropbox). Nunca é transmitida a terceiros além do fornecedor de IA que escolheu. Para a incluir nas cópias de segurança e facilitar o restauro noutro dispositivo, desative Excluir as chaves API das exportações e cópias de segurança em ⚙️ Configurações → secção Assistente IA.

Inversamente, uma chave de API presente numa cópia de segurança que importe só é instalada neste dispositivo se escolher Substituir. Uma fusão nunca a instala: é assim que se aceita a cópia de segurança de outra pessoa, e a chave dela não tem de passar a ser a sua.

Sem servidor próprio, sem rastreio

A Minha Adega de Tabaco está alojada no GitHub Pages. A aplicação não tem servidor próprio, não define cookies de rastreio e não integra ferramentas de análise (Google Analytics, etc.).

Uma exceção técnica: durante uma exportação ZIP, a biblioteca de compressão (JSZip) é descarregada a pedido da CDN cdnjs.cloudflare.com (com verificação da integridade do ficheiro). Essa CDN vê então um pedido de descarregamento normal (endereço IP, como em qualquer recurso web) — nenhum dos seus dados passa por ela; a compressão é feita inteiramente no seu dispositivo.
